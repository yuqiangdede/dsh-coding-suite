# 持久化模板与恢复协议

## 路径选择

先读目标项目规则、布局与知识索引，为每个主题建立实际路径映射。阶段分析、审查、Gate 和状态进入已登记任务工作区，常见为 `docs/_work/<task-id>/`。既有 `docs/refactor/` 只有项目允许时使用。需求、架构、ADR、接口及运维资料复用正式权威位置，状态文件只记录链接、版本和批准，不复制正文。无约定时先按项目初始化规则建立最小布局，存在冲突只暂停受影响写入。

按阶段实际内容懒创建文件，禁止一次性创建空模板。状态、能力决策、架构边界、迁移计划、验证和风险六类信息必须保留，规模小时可以合并并在状态中指明位置。

| `01-project-profile.md` | P0 环境、路径、版本、构建及运行约束 |
| `02-legacy-audit.md` | P1 功能地图、调用链、依赖、数据与证据 |
| `03-capability-inventory.md` | P2 每项能力的去留决定 |
| `04-module-boundaries.md` | P2 边界工作稿或指向已批准权威设计 |
| `05-target-architecture.md` | P3 设计工作稿或现行架构链接 |
| `06-migration-plan.md` | P3 起维护迁移顺序、依赖、兼容、切换与回滚 |
| `07-test-baseline.md` | P1 起维护特征、契约与前后端测试实际结果 |

## 00-status.md 必需字段

- 项目与任务 ID，旧/新工程绝对路径，原位或新建策略。
- 当前工作模式与授权范围，最新一次有效执行依据和批准记录链接；重新实现时记录 R 阶段、功能清单来源与覆盖缺口、功能选择、技术选型及新模块路径。
- 仓库、分支、HEAD、工作区改动摘要及相关 diff/证据引用，不保存密钥或完整敏感数据。
- 当前阶段、各阶段状态、已通过阶段的 Gate 引用与有效范围。
- 当前模块/单元 ID、进度，已保留/淘汰/暂缓/待定能力引用。
- 当前批准架构、数据所有者、API 契约与版本引用。
- 已通过测试的真实命令、环境、源码版本、时间与证据；失败、未执行、未覆盖单列。
- 未解决问题、风险、阻断原因、解除条件及需用户决定的事项。
- 下一项具体任务、前置依赖、验证命令与能否推进阶段。
- 最后更新时间与最近一轮变更摘要。

## 通用表格字段

### 项目画像与证据

项目项、值、证据类别（源码确认/运行确认/用户声明/合理推测/尚未核实）、来源位置、版本、时间、未核实原因。

### 能力清单

ID、名称、业务价值、入口/调用链、输入输出、规则、数据、依赖、缺陷、兼容要求、建议处置、已批准处置/依据、迁移复杂度、测试难度、风险等级、优先级理由。

### 架构边界

模块 ID、职责、拥有的数据、公开接口、允许依赖、禁止依赖、事务边界、异步一致性/幂等策略、关联 ADR、验证规则与批准版本。

### 迁移单元

唯一 ID、能力范围、旧/新入口、前置单元、特征与契约测试、写入所有者、数据库扩展/回填/收缩步骤、幂等/并发/失败恢复、切换开关/条件、回滚触发阈值/操作/数据处理、授权引用、实际结果。

### Gate 与验证

阶段/模块、状态、验收项、要求、命令/检查方法、环境/数据、版本/时间、退出码、实际结果、证据路径、N/A 理由、未覆盖项、审查发现、批准/风险接受、下一阶段条件。未执行不得记录为通过。

### 风险与审查

问题 ID、严重度 P0–P3、所属阶段/模块、源码/运行证据、影响、复现或验证方法、建议、责任人、阻断范围、解除条件、批准依据、复检结果。阶段 P0 与问题严重度 P0 使用独立字段。

### ADR

标题、状态、上下文与约束、真实候选方案、取舍成本风险、推荐及依据、批准人/记录、适用范围、后果、验证方式、复核或替代条件。草稿不能被状态文件引用为已批准。

## 恢复顺序

1. 从布局/索引定位本任务状态；多个活动任务无法区分时询问具体任务，不用文件时间猜测。
2. 读取状态链接的当前模块、能力决策、架构、迁移、Gate 和风险，仅按需加载。
3. 对比路径、分支、HEAD、dirty diff、源码/契约/环境及测试变化。标明已变化或未知，不能只凭旧状态判断无变化。
4. 确认受影响 Gate 的有效性与授权覆盖，失效则退回复核；保留原有历史批准及证据，不重复询问已确认且未失效的决策。
5. 选择当前阶段下一项无阻断、获授权的安全任务，结束更新状态。中断或部分失败也保存已完成范围、剩余步骤与恢复条件。

## 新工程复用

作为独立 Agent Skill 使用时，将整个 `legacy-refactor-coach/` 目录连同 references 放入该环境支持的项目 Skill 目录，例如 `.agents/skills/`。首次显式调用 `$legacy-refactor-coach`；本插件按钮及宿主斜杠命令使用 `/legacy-refactor-coach`。示例为“指导模式，审计这个 Spring Boot + Vue 工程，先做 P0”；后续说“继续重构”以状态与实际源码恢复。
