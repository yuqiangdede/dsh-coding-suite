# 关键流程问题排查指南

面向接手研发和运维，帮助从现象找到业务流程阶段、相关证据和下一步只读检查。先读取目标项目根指令、`docs/agents/document-layout.md` 与有效知识索引；遵循 [共享交接规程](../_shared/project-handover/protocol.md)、[证据](../_shared/project-handover/evidence.md)、[模板](../_shared/project-handover/templates.md) 和 [更新门禁](../_shared/project-handover/updates.md)。

## 范围和证据

用户指定模块或流程时聚焦该范围；否则先盘点项目关键入口与流程，按业务影响、跨系统边界、失败及恢复风险选择并分批整理，列出选取理由、已覆盖和未覆盖范围。记录代码版本、环境范围和分析时间，依共享规程处理未提交改动。

查找并使用项目现有的开发实现阶段确认的日志记录、工单或方案：通过索引、任务工作区、用户指定材料及相关术语定位，不假定存在固定文件或所有项目都产生此记录。记录来源、范围、确认状态及版本；只证明计划或决策，不证明日志已经实现。找不到时明确标注并继续处理其他证据，不臆造记录。

交叉核查当前版本的入口与完整关键调用链、异常和异步边界、实际日志调用与条件、日志级别/开关/输出配置、关联字段传播；参考已认可的流程/需求/设计、现有运维手册、测试、故障复盘以及用户明确提供且可访问的脱敏样本。配置仅证明配置内容，不能证明运行环境实际生效；测试和样本仅证明其环境与范围。只读本地材料，不主动连接远程或读取生产日志。区分待实现、静态核实、测试验证和运行观察，逐项给出路径、符号或配置键及版本。记录缺失日志、已删除、条件禁用、过期与证据冲突，不将未发现当作已确认不存在。临时诊断日志标为临时，不作为长期排查能力。

## 排查维度与关联

对每个关键流程按适用性核查并建立对应关系，不强求所有项目都有全部证据：

- **业务流程和规则**：入口、参与角色、前提、正常结果、状态流转、失败分支及代码或已有资料依据；区分实际行为与预期规则。
- **页面现象**：页面和操作入口、用户操作、可见提示、加载或权限表现、可安全复现的条件与浏览器端线索；没有界面证据时标待确认。
- **接口与链路**：页面到接口、服务、异步任务和外部依赖的调用及失败边界；关联请求标识、响应状态、错误码、重试与超时，不能凭接口名推断结果。
- **数据库数据与状态**：依据源码或已认可的数据库文档定位实体、表和字段、业务主键、状态及关联关系，说明预期与异常状态、时间和一致性检查；仅在证据充分时给出带限定条件、脱敏占位符的只读查询示例。不连接数据库、不查询真实数据；未知结构或权限标待确认，不给无条件全表查询。
- **打印日志与观测**：日志事件、级别、位置、开关、时间、关联键和异常栈；必要时关联指标、链路追踪、告警或任务状态，缺失时说明替代证据。
- **环境与变更**：版本、环境、配置开关、权限、网络和依赖状态，以及已知发布或配置变更时间；静态配置不等于运行状态，不能假定某次变更就是原因。

从页面现象或业务事件出发串联业务 ID、请求或追踪 ID、时间范围与时区，按页面 → 接口 → 业务逻辑 → 数据状态 → 日志及依赖提出可执行的只读定位顺序；实际顺序按现象调整。每一步写明证据来源、正常与异常判断依据、分支和下一步，区分事实、假设、未核验和证据冲突。缺少权限、环境或证据时说明阻塞、所需材料和由授权人员执行的检查，不宣称已验证。不能从当前数据直接推断历史状态或因果关系。

## 展示与输出

首先给一张“现象/业务流程 → 页面/接口 → 数据状态 → 日志/依赖 → 关联字段 → 排查章节”的导航表；未知值写待确认。对每个关键流程按实际顺序提供：触发条件、主要阶段与分支；每阶段可观察的日志事件、级别、日志源或配置位置、关联键和代码证据；从入口到异常出口的只读定位步骤；缺日志或未找到关联键时的下一证据及局限。说明异步/跨服务关联断点、重试或重复事件可能造成的歧义，不以缺少某条日志断言某步骤未执行。

如有确凿依据，提供适用于对应环境和工具的安全只读查询示例，参数使用占位符并说明时间范围、时区和适用前提；未知平台不猜命令、路径或字段。示例使用合成数据或充分脱敏，禁止凭据、个人数据与真实业务记录。整理证据清单、差异和待确认项：开发记录中的期望、源码静态事实、验证状态、影响和下一核实方法分别列出。标注版本、环境和未验证范围；运行结果不能由源码推断。

复用现有权威排查文档及流程章节，以链接避免复制，缺少时按布局提出合适位置。先在对话展示每个文件的具体新增内容或差异、来源和冲突；必须取得本次差异的明确确认后才写正式文档，写前重新检查文件状态。未确认则仅交付预览。不得修改业务代码、日志或配置，不执行生产操作、提交或推送。
