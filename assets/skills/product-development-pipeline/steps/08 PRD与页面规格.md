# Step 08：页面规格

直接将 Step 01–07 已确认的业务方案、模块边界、流程、状态及权限整理成页面规格。复用已有材料，按实际页面规模裁剪。核心业务缺口影响页面时回退对应阶段。

## 页面规格

页面来自已确认业务任务，不重新设计业务。

每个页面至少输出：

- PageId / 页面名称。
- 使用角色与进入场景。
- 页面目标。
- 页面入口和返回路径。
- 布局区域。
- 核心字段/表格列/筛选项。
- 主要操作。
- 操作对应的前置状态和结果状态。
- 可见权限 / 操作权限。
- 正常、空、加载、失败、禁用等必要状态。
- 涉及的异常处理入口。
- 是否需要 UI 效果图或可运行原型。

## 全局页面配置

记录：

- 标签语言。
- 示例数据语言。
- 已确认全局视觉约束（如有）。

这些只是展示配置，不得反向改变业务规则。

## 输出

- 页面清单和页面规格。
- 全局展示配置。
- 影响 UI 的待确认项（如有）。

完成后进入 Step 09 页面-流程-权限一致性 Gate。
