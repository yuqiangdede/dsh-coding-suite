# Markdown 转 Excel

读取用户指定的 Markdown，未指定输入时询问。遵循目标项目的文档布局与正式资料写入规则。默认在允许的位置生成同名 .xlsx，保留源文件；目标已存在时先取得覆盖确认。

根据内容和用户要求设计工作表，保留章节顺序、标题、段落、列表、代码和表格；表格按行列写入，多个表格可按章节分表。无法映射到单元格的内容作为文本保留；图片、公式、链接等无法完整表示时保留文字或目标并报告限制。不要补写或改变事实。数据默认按原文文本写入，保留前导零及长数字，不将源文本当作 Excel 公式执行。

使用环境中可用的电子表格工具创建真正的 XLSX；如有可用的 spreadsheets Skill，遵循其制作和验证流程。缺少工具时说明限制，不伪造文件或更改扩展名。为可读性设置标题、换行、列宽和冻结窗格，避免改变内容。

重新打开生成的工作簿，核对工作表、章节、表格行列及关键文本与源文件一致；检查公式注入和文本截断，条件允许时预览版面。报告输出路径、检查结果和未能保留的内容。不修改源文件、不提交或发布。
