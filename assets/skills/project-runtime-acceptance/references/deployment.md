# DEPLOY：部署配置与多实例行为

## 规则

| ID | 检查点 | 说明 |
| --- | --- | --- |
| DEPLOY-001 | 多实例导致任务/缓存重复或不一致 | 结合 JOB 与 CACHE，检查实际副本数 |
| DEPLOY-002 | 环境配置差异影响清理 | 生产 cron、开关、TTL、桶路径与测试不同 |
| DEPLOY-003 | 密钥/地址/端口硬编码 | 不应泄漏凭据；集中配置且默认安全 |
| DEPLOY-004 | 启动/健康检查依赖不完整 | 未就绪即接流量、迁移竞争、启动依赖缺失 |
| DEPLOY-005 | 优雅停机缺失 | 在途任务中断与重复触发 |
| DEPLOY-006 | 升级/回滚不兼容 | 旧版本、新版本并存的 schema/消息结构兼容 |
| DEPLOY-007 | 单点/容量配置缺失 | 关键服务或队列没有故障替代与阈值 |
| DEPLOY-008 | 资源请求/限制不合理 | JVM、容器 OOM、磁盘临时空间、线程池预算 |
| DEPLOY-009 | 时钟/时区/证书处理不一致 | token 过期、TTL、任务时区差异 |
| DEPLOY-010 | 部署清单与源码不一致 | 运行实例/任务/变量/权限的真实配置应核实 |

证据：Docker Compose、K8s 清单、Helm、配置文件、CI/CD 与实际部署元数据（获授权只读）。缺少生产配置时记录 `未覆盖`，不默认开发配置等同线上配置。
