## 功能排查日志

复用现有 logger、级别、关联 ID 与局部开关，不新增排查页面。以一次业务 runId 串联开始、关键步骤、条件分支/回退、异常及最终摘要；并发执行不能串线。异步链路保留关联 ID，输出顺序不等于执行顺序，保留步骤序号/父子标识和时间线索。

日志包含步骤/服务、技术调用状态、业务结果、白名单关键输入输出摘要、异常及最终结论；接口成功无数据应明确写“调用成功、无数据”，回退写原因和结果。缺少最终反馈写未验证，不用一条接口成功日志判定业务完成。按共享约定控制敏感数据、体积和刷屏，默认关闭额外采集，不全局开启 debug。

交付日志启停、按 runId 检索、复现取证与阅读步骤的方法；样例标明模拟数据，不编造已采集结果。临时探针遵循 TEMP-DIAG 清理和提醒规则。
