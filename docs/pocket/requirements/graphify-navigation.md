# 可选代码图谱导航

状态：accepted。范围：套件中的 Graphify 可选入口；不改变目标项目的知识权威。

- 初始化诊断报告 Graphify CLI 和当前项目图谱是否存在，并介绍可选入口；诊断不安装、建图或配置后台任务。
- 内置 `graphify-navigation` 技能和「代码图谱」按钮。用户点击按钮并发送后，CLI 缺失时自动安装官方 `graphifyy`；用户指定后手动建图、刷新或查询，未指定操作时检查状态和介绍选项。旧按钮配置可通过现有的添加缺失默认按钮功能选择加入。
- 首次和刷新默认代码本地提取；文档及其他语义处理需用户明确选择。自动安装使用已有 uv 或 pipx，不自动安装前置工具；失败时回退普通搜索，不阻断工作。非按钮调用按用户实际授权决定是否安装。
- 不默认启动监听器、任务或 Git hook。图谱为可过期的派生线索；重要结论须回源核实。Pocket 和目标项目现有知识源保持权威。
- 上游为 [Graphify](https://github.com/Graphify-Labs/graphify)，本套件提供独立集成说明，不复制或捆绑上游代码；安装版本和实际 CLI 行为以用户环境为准。
