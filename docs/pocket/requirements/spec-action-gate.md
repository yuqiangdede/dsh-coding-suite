# 固化需求按钮的前置条件

状态：accepted（2026-10-26 用户确认）

范围：Skill Launcher 的 `spec` 动作。

- 默认显示但置灰，点击不得插入草稿。
- 当前会话的「需求讨论」或「可视化讨论」形成结论后解锁；仅结束一个尚在提问的回合不算完成。
- 讨论的后续回答可以形成结论，不要求结论与启动讨论处于同一回合。
- 失败、中断及运行中的会话不解锁。
- 已形成的结论在当前会话内有效，后续普通对话不重新锁定。切换会话时不继承其他会话的解锁状态。
- 输入框不可用、配置未加载或插入请求处理中时，仍遵循原有通用禁用规则。

实现依据：从当前可见会话历史重建讨论状态，复用下一步推荐的需求结论判定，并排除疑问、否定及失败回合。目前没有结构化讨论完成事件，结论识别依赖可见文本；未加载的历史不能作为解锁依据。此规则仅约束按钮，不拦截用户手动输入 Skill 命令。

回归入口（Node.js 24+）：`npm run test:spec-gate`，覆盖会话判定和发布 bundle 的按钮禁用/插入行为。
