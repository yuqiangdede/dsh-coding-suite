# 开发分组改名与更多按钮

状态：accepted。来源：2026-10-28 用户要求“需求开发”分组改名“开发”，按钮过多时增加更多；已确认每组默认 8 个、组内展开/收起及测试边界。

## 交互约定

- “需求开发”显示名改为“开发”，英文为 `Development`；沿用 `development` 分组 ID。发射器分组开关、标题与设置界面共用字典，不修改已保存的按钮或分组配置。
- 常用、开发、文档编写、其他各组独立折叠。仅当该组启用且可用的按钮数超过 8 时显示“更多（剩余数量）”；默认只展示现有顺序的前 8 个，不把禁用项计入数量。
- 点击“更多”在组内原位展开全部按钮，出现“收起”；点击收起回到前 8 个。少于等于 8 个不显示更多；窄屏沿用换行，不引入依赖窗口测量的溢出阈值。
- 展开是组件内的临时展示状态，不保存 Host 配置、不插入草稿或发送消息；各组互不影响，刷新/重新挂载后收起。只读设置或执行锁不妨碍浏览展开项，动作本身仍遵循既有禁用与草稿插入规则。
- 折叠区存在推荐动作时，“更多”显示提示点，现有推荐说明仍显示完整动作名称；不重排按钮。更多/收起使用原生按钮、组名限定的无障碍名称及 `aria-expanded`，支持键盘操作。
- 没有新增动作、Skill 或提示词；仍由现有按钮设置管理顺序、成员与启用状态。

## 常用分组显示设置（2026-10-28）

- “显示分组”增加常用开关，设置页也可勾选常用；常用组内提供隐藏按钮，隐藏后可通过显示分组开关恢复。所有分组可独立显示或隐藏，隐藏不改变按钮成员、顺序或提示词。
- 默认显示常用；旧布局缺少 common 字段时按显示处理，显式 true/false 随布局保存、导入和导出。只读或保存失败时沿用现有分组设置行为。

## 页面内编辑常用（2026-10-28）

- 显示分组一行提供“编辑常用”，无论常用组是否显示均可进入。编辑面板列出所有已启用的按钮（包括自定义按钮），勾选或取消后点击保存生效；取消放弃本次选择。编辑时隐藏动作分组，避免误触执行。未启用或暂时缺失的成员保留原配置；新勾选的按钮追加到已有顺序。
- 仅保存布局中的常用成员，不修改动作本身或分组显示状态。只读、配置无效或没有版本时不能进入编辑；版本冲突或保存失败时保留编辑内容并提示，取消后可重新进入。常用成员仍受布局上限 100 个约束。
- 编辑面板按需求、开发、文档、其他分组展示已启用按钮，沿用各分组的成员与顺序，不受分组显隐影响；属于多个分组的按钮在各组显示并共享勾选状态。没有业务分组的常用预设及自定义按钮归入“其他”，空组不显示。
