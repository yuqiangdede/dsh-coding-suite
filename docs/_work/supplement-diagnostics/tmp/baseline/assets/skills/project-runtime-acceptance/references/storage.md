# STORE：文件、对象存储及数据库关联资源

## 资产分类

检查本地目录、共享盘、S3/OSS/MinIO、FTP 摆渡、图片缩略图、录像/转码产物、预览临时副本、导出 ZIP/PDF、上传分片、生成缓存、备份和日志。记录 `存储桶/目录/key 模板 / 生成方 / 持有业务记录 / 生命周期 / 归档 / 删除机制 / 上限 / 失败重试 / 法律保留依据`。

## 规则

| ID | 检查点 | 失败情形 |
| --- | --- | --- |
| STORE-001 | 数据库删除未删除关联对象 | 孤儿文件/对象不断增长 |
| STORE-002 | 对象删除未更新数据库引用 | 页面返回 404、悬空引用 |
| STORE-003 | 临时文件缺 TTL | 转码/上传/下载/导出中间物长期存储 |
| STORE-004 | 对象存储生命周期规则失效 | 前缀、版本控制、删除标记、分片和策略未生效 |
| STORE-005 | 归档前误删源 | 先验证已成功且可恢复归档，再触发清理 |
| STORE-006 | 清理批次不可恢复 | 幂等删除、重试、失败记录、限流及熔断 |
| STORE-007 | 无可用容量或增长监控 | 磁盘/桶容量、清理积压、可用空间告警 |
| STORE-008 | 多个网络/存储副本生命周期不同步 | 摆渡临时目录与正式归档策略区别 |
| STORE-009 | 安全/合规例外被误删 | 保留锁、法规保留、审计日志与备份 |
| STORE-010 | 文件外链失效/泄露 | 临时授权链接 TTL 与权限隔离 |

## 跨存储闭环示例

`业务ID → 事件表 → 图片对象 → 原始录像 → 转码文件 → 临时观看副本 → 归档副本`，每一跳给 key 生成规则与清理触发事件。即使某资源有外部桶生命周期，缺少运行证据时仍标为待验证。

不要在验收阶段运行清理、遍历下载大量生产文件或列出敏感对象内容。
