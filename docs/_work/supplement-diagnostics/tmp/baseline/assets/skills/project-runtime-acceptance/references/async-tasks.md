# ASYNC：消息队列与异步任务可靠性

## 资产

RabbitMQ/Kafka/RocketMQ/Redis Stream/SQS/Celery/自建任务表。每主题/队列记录：生产者、消费者、持久化策略、分区/并发、确认时机、幂等键、重试/死信、任务状态、超时/取消、积压水位、处理优先级与恢复方式。

## 规则

| ID | 规则 | 典型症状 |
| --- | --- | --- |
| ASYNC-001 | 投递与 DB 提交不一致 | DB 成功却没发消息，或发消息后 DB 回滚 |
| ASYNC-002 | 重复消费非幂等 | 重复写库、重复通知、重复转码 |
| ASYNC-003 | ack/提交偏移时机错误 | 丢消息、无限重试或重复执行 |
| ASYNC-004 | 无限重试/缺死信 | 故障消息阻塞队列，重试风暴 |
| ASYNC-005 | PROCESSING 永久滞留 | 服务宕机/崩溃后任务无法恢复 |
| ASYNC-006 | 顺序依赖未保护 | 事件乱序、旧状态覆盖新状态 |
| ASYNC-007 | 无积压容量/告警 | 消费速率长期低于生产速率 |
| ASYNC-008 | 过期任务不回收 | 失败任务、临时消息、outbox 记录无限增长 |
| ASYNC-009 | 延迟队列/定时补偿冲突 | JOB 重复重放，造成状态错乱 |
| ASYNC-010 | 服务关闭时未妥善收尾 | 在途消息/任务被丢弃或重复处理 |

验证：消费滞后、DLQ 数、最旧任务时间、成功/失败状态迁移、服务重启后的补偿记录。没有环境权限时用只读验证清单，不声称“运行正常”。
