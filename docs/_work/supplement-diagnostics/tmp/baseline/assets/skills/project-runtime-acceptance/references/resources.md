# RES：资源泄漏与长期稳定性

## 资产

线程/线程池/异步协程、数据库/HTTP/Redis 连接池、WebSocket/订阅、文件句柄、内存缓存/队列、直接内存、定时器、临时文件、日志写入器、视频/图片解码与转码进程。

## 规则

| ID | 检查点 | 证据 |
| --- | --- | --- |
| RES-001 | 连接未关闭/归还 | with/try-with-resources/finally、异常分支 |
| RES-002 | 线程/协程任务无限创建 | 并发上限、背压、取消和关闭路径 |
| RES-003 | WebSocket/事件监听重复注册 | 页面/会话销毁与监听器取消 |
| RES-004 | 缓存/集合/队列无上限 | 长时间增长趋势、最大容量/淘汰策略 |
| RES-005 | 超时和取消未传播 | 上游取消后下游持续运行 |
| RES-006 | 应用退出不优雅 | 在途任务、句柄和线程池释放 |
| RES-007 | 临时文件/进程残留 | 异常路径清理、转码子进程回收 |
| RES-008 | 日志/追踪无轮转保留 | 日志无上限撑满磁盘 |
| RES-009 | 执行器拒绝策略错误 | 任务丢弃/CallerRuns 阻塞和资源放大 |
| RES-010 | 资源容量缺监控 | 线程数、FD、内存堆/堆外、连接数、队列深度 |

## 运行验证

在隔离环境负载后对照稳态资源曲线；需要 24h/72h 趋势时应明确这是建议测试，不可伪造已经观察。高水位但稳定的连接池与缓存不等于泄漏，关注负载回落后是否持续单向增长。
