## DSH Coding Suite 所有 Skills 统一文档与中间产物规则

执行任意需求、研发、Bug 排查、审查、Gate、验收、交接、转换、运维、研究 Skill 前，如需**读取、生成、修改、依赖任何项目文档或阶段文件**，必须先读取目标项目的 `docs/agents/document-layout.md`、根 Agent 指令与该布局指向的知识索引；未创建的项目先运行 `/setup-matt-pocock-skills`，不自行另建目录。

- **正式文档**：依初始化登记的当前权威路径，复用已有需求、PRD、设计、ADR、接口、数据库、部署、运维、验收、交接资料；某项确实缺失时才在该布局登记的回退目录创建。不采用本 Skill 自带的冲突默认目录，不为同一主题复制第二份。
- **阶段中间文件**：需求池、源码分析、评审、Gate、状态快照、提取记录、转换 part、job-manifest、临时报告统一放在布局指定工作根目录下的 `<task-id>/`；缓存归于任务 `tmp/`。必要时记录阶段、源文件/版本、状态和关联正式文档；不需要落盘的工作不强制新建文件。
- **外部工单**：Issue Tracker/远端服务按 `docs/agents/issue-tracker.md` 约定为权威，本地仅记录引用或获确认的工作稿。
- **写入权限**：正式文件创建、增量改写、迁移、合并、删除和目录布局变更，先给路径清单及差异、取得明确确认；任务原有更严格限制仍生效。初始化阶段已授权按 [自动决策规程](SETUP_AUTO_DECISIONS.md) 对唯一确定、非破坏性的工程骨架与技术路径错字直接采用推荐并建立布局及工作区 README，复用现有权威目录，不迁移。
- 布局缺失、版本无效、路径冲突或目标不存在时，报告缺项并停止**文件写入**；只读分析可继续。末尾列出实际产物路径及权威状态，未写入不谎报。
