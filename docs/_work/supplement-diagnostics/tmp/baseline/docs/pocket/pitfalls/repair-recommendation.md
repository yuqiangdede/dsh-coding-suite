# 修复完成后仍推荐修复

状态：accepted。范围：快捷栏基于会话文本的下一步推荐。

旧版或自定义修复提示词与当前默认按钮签名不一致时，会回落到关键词匹配；其中的“审查”会优先命中审查阶段。修复报告中的 P1 等已解决问题编号又会被当成审查发现，因此继续高亮修复。另一个误判来源是报告介绍、空栏目中的“未修复项”。

处理规则：按钮签名仍优先；回落匹配时，明确要求修复的请求应归入修复阶段。检查遗留问题时排除栏目介绍、空标题及明确为空的列表；真正未修复的问题仍推荐修复。修复成功则按现有流程推荐编译和代码审查。

实现见 `src/client/contextual-actions.ts`；回归测试见 `tests/recommendation-outcomes.node.test.mjs`，同时核对源码和发布包行为。
