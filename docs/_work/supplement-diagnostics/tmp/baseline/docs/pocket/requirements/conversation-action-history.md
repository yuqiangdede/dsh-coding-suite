# 对话中的按钮使用顺序

状态：accepted（2026-10-28，用户要求在各对话中展示之前调用的按钮及自由对话顺序）。

## 交互和识别

- 在输入区“显示分组”同一行末尾展示当前对话的已发送用户消息，不显示记录标题；空间不足时换行。连续相同标签合并计数（如“自由对话*2”），不连续的同名标签不合并。按最新在前排列，用向左箭头指向较新的记录；默认显示最近五组，可以展开全部。运行中仍可查看，切换对话随当前视图更新。
- 匹配当前按钮配置的完整插入内容时显示按钮名称；消息以斜杠命令开头、且只有一个按钮绑定该 Skill 时，同样识别为该按钮（提示词改版、旧配置或手动补充内容后仍可识别）。多个按钮共用同一 Skill 时仍按完整内容区分，无法区分时不猜测。普通文本或无法识别的消息显示“自由对话”，无法匹配的斜杠命令显示命令本身。消息没有文本时不显示。
- 点击任一记录可定位到本对话中的对应消息：滚动到该条消息并短暂高亮，位于折叠组内时先展开。合并计数的记录定位到其中最新一条；记录提示中显示该消息文本的开头，便于区分同名记录。无法定位（已切换视图、消息未加载或只能读到兼容节点）时在输入区提示，不猜测位置，也不重发、改写或重新提交该消息。
- 记录从当前可用的聊天视图即时推导，不新增存储、不读取其他会话；仅点击而未发送的草稿不计入。由于 Host 没有提供可靠的按钮点击来源，手动输入同样内容可能被识别为按钮；按钮配置修改、草稿改写或历史未加载也可能导致无法识别。展示是识别结果，不表示执行成功。
- 名称使用当前配置，因此改名后历史展示也随之变化。按钮被删除后不能保证识别原有历史。英文界面提供相应文案。
