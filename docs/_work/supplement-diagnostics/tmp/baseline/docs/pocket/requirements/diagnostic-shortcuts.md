# 日志分析与远程调试入口

状态：accepted。用户要求在“增加日志”后增加“分析日志”，末尾增加“远程调试”，并将“文档编写”改名为“文档”。

- 两个入口均为纯提示词动作：点击插入可编辑草稿，用户填写后自行发送；不会自动分析日志或连接 SSH。常用和开发组中分析日志紧随增加日志，远程调试位于末尾，沿用组内更多/收起规则。
- 分析日志提供日志文件或目录路径填写位置，缺失或不可访问时询问，基于证据分析，不修改代码、日志或配置。
- 远程调试提供 SSH 连接信息、远程运行路径和问题描述填写位置，缺项先询问；使用现有认证，优先只读诊断，远程变更先征求确认。不要在草稿中填写密码、私钥或令牌。
- 文档分组显示名改为“文档”，分组 ID 不变；英文仍为 Documentation。已保存的动作及布局不自动覆盖，旧用户可在按钮设置中补齐缺失预设并保存；自定义常用组需自行添加新动作。
- 默认提示词以 [actions.ts](../../../src/client/actions.ts) 为准；[回归测试](../../../tests/diagnostic-shortcuts.node.test.mjs)覆盖输入、顺序和配置兼容，发射器测试覆盖草稿插入。
